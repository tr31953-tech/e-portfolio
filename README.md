# 🌐 E-Portfolio | ก้องภพ นพรัตน์นภาลัย (Kongphop Nopparatnapalai)

เว็บไซต์รวบรวมประวัติส่วนตัว ทักษะ ผลงานด้านการพัฒนาซอฟต์แวร์ และกิจกรรมต่างๆ ของ **นายก้องภพ นพรัตน์นภาลัย** พัฒนาในรูปแบบ Single-Page Application ด้วย HTML, CSS และ JavaScript โดยไม่ต้องพึ่งพา Framework ภายนอก และพร้อมเผยแพร่ผ่าน **GitHub Pages**

🔗 **Live Demo:** [https://kongphop-example.github.io/](https://kongphop-example.github.io/) *(เปลี่ยนเป็นลิงก์ GitHub Pages จริงของคุณ)*

---

## ✨ คุณสมบัติหลักของเว็บไซต์ (Features)

* **โครงสร้างครบถ้วน 4 ส่วนหลัก:** ประกอบด้วย หน้าแรก (Home), แนะนำตัว (About), ผลงาน (Projects) และกิจกรรม (Activities)
* **ดีไซน์ทันสมัย โทนสีน้ำเงิน-ขาว:** ออกแบบให้ดูสะอาดตา มีความเป็นมืออาชีพ และอ่านง่าย
* **รองรับภาษาไทยสมบูรณ์:** ใช้ฟอนต์ **Prompt** จาก Google Fonts เพื่อการแสดงผลภาษาไทยและภาษาอังกฤษที่สวยงาม
* **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ พร้อมเมนู Hamburger บนมือถือ
* **Single-File Architecture:** รวมโครงสร้าง HTML, การตกแต่ง CSS และการทำงานของ JavaScript ไว้ในไฟล์ `index.html` เพียงไฟล์เดียว ง่ายต่อการดูแลและอัปเดต

## 🚀 อธิบายผลงานที่แสดงบนเว็บไซต์ (Projects Overview)

ภายในส่วน **ผลงานเด่น (Projects)** ได้รวบรวมโครงงานตัวอย่างที่ได้พัฒนาขึ้น เพื่อแสดงทักษะการแก้ปัญหาและการเขียนโปรแกรม ดังนี้:

### 1. ระบบจัดการตารางงานและบันทึกช่วยจำ (Task Manager & Notes)
* **คำอธิบาย:** เว็บแอปพลิเคชันสำหรับจดบันทึกและจัดลำดับความสำคัญของงานประจำวัน ช่วยให้ผู้ใช้สามารถเพิ่ม แก้ไข และทำเครื่องหมายเมื่อทำงานเสร็จสิ้นได้อย่างสะดวก
* **จุดเด่นทางเทคนิค:** พัฒนาด้วย HTML5, CSS3 และ Vanilla JavaScript มีระบบบันทึกข้อมูลลงใน **LocalStorage** ของเบราว์เซอร์ ทำให้ข้อมูลไม่สูญหายแม้ปิดหน้าเว็บไปแล้ว
* **Repository:** [github.com/kongphop-example/task-manager](https://github.com/kongphop-example/task-manager)

### 2. เว็บคำนวณวางแผนการออมเงิน (Saving Planner Calculator)
* **คำอธิบาย:** เครื่องมือช่วยคำนวณเป้าหมายการออมเงินรายเดือนและผลตอบแทนจากดอกเบี้ยทบต้น เพื่อช่วยให้ผู้ใช้งานสามารถวางแผนทางการเงินได้อย่างเป็นรูปธรรม
* **จุดเด่นทางเทคนิค:** ใช้ JavaScript ในการคำนวณสมการทางการเงินแบบ Real-time ทันทีที่ผู้ใช้กรอกข้อมูล ออกแบบหน้าจอให้ใช้งานง่ายและรองรับการใช้งานบนสมาร์ทโฟน
* **Repository:** [github.com/kongphop-example/saving-calculator](https://github.com/kongphop-example/saving-calculator)

### 3. เว็บไซต์แนะนำสถานที่ท่องเที่ยวชุมชน (Local Travel Guide)
* **คำอธิบาย:** เว็บไซต์ประชาสัมพันธ์แหล่งท่องเที่ยว อาหารพื้นถิ่น และวัฒนธรรมของชุมชน เพื่อส่งเสริมการท่องเที่ยวเชิงอนุรักษ์และกระจายรายได้สู่ท้องถิ่น
* **จุดเด่นทางเทคนิค:** เน้นโครงสร้างเว็บไซต์ที่โหลดรวดเร็ว จัดวางเนื้อหาและรูปภาพอย่างเป็นระเบียบตามหลัก UI/UX เบื้องต้น พร้อมระบบค้นหาและคัดกรองข้อมูลสถานที่
* **Repository:** [github.com/kongphop-example/local-travel-guide](https://github.com/kongphop-example/local-travel-guide)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5:** โครงสร้างหลักของเว็บไซต์ (Semantic HTML)
* **CSS3:** การจัดรูปแบบ Flexbox, CSS Grid, ตัวแปรสี (CSS Variables) และ Media Queries
* **JavaScript (ES6+):** การควบคุมเมนูนำทางบนมือถือ (Responsive Navbar) และการอัปเดตปีลิขสิทธิ์อัตโนมัติ
* **Google Fonts:** ฟอนต์ `Prompt`
* **Font Awesome 6:** ไอคอนประกอบส่วนต่างๆ ของเว็บไซต์ (ผ่าน CDN)
